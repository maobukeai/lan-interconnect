# 局域网互联 - React Native Android 移动端项目总览

## 📱 项目简介

局域网互联 Mobile 是一个功能完整的跨平台文件共享与通信工具，实现与 PC 端（Electron）的无缝连接和三端互通。

**技术栈**: React Native + TypeScript + Redux Toolkit + Material Design 3

## 🚀 快速开始

### 方法 1: 使用初始化脚本（推荐）

```bash
cd mobile
init-project.bat
```

### 方法 2: 手动创建

```bash
# 1. 创建项目
npx @react-native-community/cli@latest init LanDiskMobile --version 0.74.0 --pm npm

# 2. 安装依赖
cd LanDiskMobile
npm install @react-navigation/native @react-navigation/stack
npm install @reduxjs/toolkit react-redux axios
npm install react-native-paper react-native-vector-icons
npm install react-native-fs react-native-document-picker
npm install react-native-vision-camera react-native-qrcode-svg
npm install event-source-polyfill

# 3. 复制源代码
将 src/ 目录复制到项目根目录
```

### 运行应用

```bash
# 启动 Metro Bundler
npm start

# Android 调试
npm run android

# 构建 APK
npm run build:apk
```

## 💻 核心代码示例

### 连接服务器

```typescript
import { connectionService } from './services/ConnectionService';

// 连接到电脑
const result = await connectionService.connect(
  'http://192.168.1.100:3000', 
  '123456'
);

if (result.success) {
  console.log('连接成功！');
  // 自动跳转到 Dashboard
} else {
  Alert.alert('连接失败', result.error);
}
```

### 获取文件列表

```typescript
import { fileAPI } from './api/endpoints';

// 获取 C 盘文件列表
const files = await fileAPI.getFiles('C:\\');
console.log(files);

// 下载文件
const blob = await fileAPI.downloadFile('C:\\file.txt');
```

### 发送聊天消息

```typescript
import { connectionService } from './services/ConnectionService';

// 发送文本消息
await connectionService.sendMessage('你好！', 'text');

// 发送图片（Base64）
await connectionService.sendMessage(
  'data:image/png;base64,...', 
  'image'
);
```

// 指数退避算法：1s → 2s → 4s → 8s
private scheduleReconnect(serverUrl: string, pin: string) {

  setTimeout(() => this.initSSE(serverUrl, pin), delay);
}
