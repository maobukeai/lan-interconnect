# 局域网互联 Mobile - APK 打包与安装指南

## 📦 方法一：使用打包脚本（推荐）

### 步骤 1: 运行打包脚本

```bash
# 双击运行
mobile\build-apk.bat
```

或手动执行：
```bash
cd mobile\LanDiskMobile\android
gradlew assembleDebug
```

### 步骤 2: 等待编译完成

**首次编译需要 5-10 分钟**，因为需要：
- 下载 Gradle（约 100MB）
- 下载 Android 依赖库
- 编译 React Native 和所有组件

**后续编译只需 1-2 分钟**

### 步骤 3: 找到 APK 文件

编译成功后，APK 文件位置：
```
mobile\LanDiskMobile\android\app\build\outputs\apk\debug\app-debug.apk
```

## 📱 安装到手机

### 方法 A: USB 传输安装

1. **连接手机到电脑**
   - 使用 USB 数据线
   - 开启手机"文件传输"模式

2. **复制 APK 到手机**
   ```bash
   # APK 路径
   mobile\LanDiskMobile\android\app\build\outputs\apk\debug\app-debug.apk
   ```

3. **在手机上安装**
   - 打开手机文件管理器
   - 找到 APK 文件
   - 点击安装
   - 允许"未知来源应用"

### 方法 B: 直接通过 ADB 安装

```bash
# 确保手机已连接并开启 USB 调试
adb devices

# 安装 APK
adb install mobile\LanDiskMobile\android\app\build\outputs\apk\debug\app-debug.apk
```

### 方法 C: 通过网络分享

1. **微信/QQ 发送到手机**
   - 将 APK 通过微信/QQ 发送到手机
   - 在手机上点击下载
   - 安装应用

2. **局域网共享**
   - 在电脑上开启文件夹共享
   - 手机访问电脑 IP 下载 APK

## ⚠️ 常见问题解决

### 问题 1: "SDK location not found"

**解决方案**:
1. 打开 `mobile\LanDiskMobile\android\local.properties`
2. 添加（修改为你的 SDK 路径）:
   ```properties
   sdk.dir=C\:\\Users\\你的用户名\\AppData\\Local\\Android\\Sdk
   ```

### 问题 2: "Gradle 下载失败"

**解决方案**:
```bash
# 使用国内镜像
# 编辑 android/build.gradle

# 将
mavenCentral()

# 改为
maven { url 'https://maven.aliyun.com/repository/google' }
maven { url 'https://maven.aliyun.com/repository/public' }
```

### 问题 3: "编译内存不足"

**解决方案**:
```bash
# 编辑 android/gradle.properties
# 添加或修改
org.gradle.jvmargs=-Xmx4096m -XX:MaxPermSize=2048m
```

### 问题 4: "签名错误"

**解决方案**: Debug 版本不需要额外配置，直接使用即可

## 📊 编译进度说明

### 正常编译流程
```
> Task :app:compileDebugJavaWithJavac
> Task :app:bundleDebugJsAndAssets       ← 打包 JS 代码
> Task :app:compressDebugAssets         ← 压缩资源
> Task :app:processDebugResources       ← 处理资源文件
> Task :app:packageDebug                ← 打包 APK
> Task :app:assembleDebug               ← 完成！
```

### 预计耗时
| 阶段 | 首次 | 后续 |
|------|------|------|
| 下载 Gradle | 2-5 分钟 | - |
| 下载依赖 | 3-5 分钟 | 1-2 分钟 |
| 编译 Java | 1-2 分钟 | 30 秒 |
| 打包资源 | 1-2 分钟 | 30 秒 |
| **总计** | **8-15 分钟** | **2-3 分钟** |
