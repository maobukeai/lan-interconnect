# 🐾 猫步互联 Pro (LanDisk Pro)

> **极简、高保真、影院级局域网文件共享与跨设备协同中枢**  
> 纯原生体验 · 零外网依赖 · 毫秒级极速互传 · 影音剧场 · 远程硬件控制

---

## 🌟 核心特性与架构矩阵

### 1. 📁 极速文件流转与多端互联
- **⚡ Web Worker 异步分片与采样指纹**：超大文件（10GB+）后台计算哈希，主线程 60FPS 丝滑不卡顿；
- **🛡️ 毫秒级秒传探测与断点续传**：断网自动重试与背压流式写入，内存占用恒定 < 15MB；
- **🔄 全局书签与文件操作**：支持常用目录动态绑定、在线文本/代码编辑、一键新建文件与批量移入回收站；
- **💾 防突发断电原子写盘**：传输记录、回收站元数据、黑名单与别名配置全面采用 `.tmp` + `renameSync` 原子置换。

### 2. 🎬 院线级影音剧场 (Media Theater)
- **🧠 智能影视元数据刮削**：自动过滤压制组与参数噪点，提取剧名、年份、季集（如 `S1:E3`）与 4K/1080P Badge；
- **⚡ 本地海报 0ms 直出**：同名海报自动探查，直推原图 0 CPU 开销；
- **⏱️ 时间分桶进度预览**：进度条悬停 5 秒时间分桶缩略图预览与 ffmpeg 并发闸门限流；
- **⌨️ 专业播放器快捷键矩阵**：空格/K 暂停、J/L ±10s、0-9 百分比跳转、逐帧步进（`,`/`.`）、A-B 复读与 4K 高清截图。

### 3. 📋 跨端剪贴板与 iMessage 级实时聊天
- **📋 AirDrop 级图文双向互通**：支持文本与 PNG 二进制图片在手机与电脑间双向粘贴同步；
- **💬 SSE 实时事件流与 25s 心跳保活**：支持文字、语音留言、图片消息与 URL 链接安全自动高亮转换。

### 4. 🖥️ 远程桌面与系统硬件遥控
- **📡 实时屏幕串流**：低延迟 JPEG 画面 WebSocket 流式下发与帧率/画质动态自适应；
- **🖱️ 硬件级键鼠与手势映射**：高精度触控板平滑移动、滚轮滚动与双重防误触电源管理（关机/重启/休眠/锁定）。

### 5. 🌐 零配置本地域名广播 (mDNS)
- 内置 UDP 5353 多播域名响应，同一局域网设备直接输入 `http://landisk.local:3000` 即可直连访问。

## 🚀 快速启动

### 本地启动 Node.js 服务
```bash
# 启动服务
node server.js
```

### 构建多端 Web 产物
```bash
# 构建桌面端 web bundle (desktop-dist)
node scripts/build-desktop-web.js

# 构建移动端 web bundle (mobile-dist)
node scripts/build-mobile-web.js
```

## 🔒 安全与隐私防御规范
1. **严格路径安全（Path Traversal 防护）**：防范 `../` 穿透与 UNC 网络共享跨机访问；
2. **XSS 契约与内容净化**：数据层存原文，渲染层强制 `escapeHtml` 转义，文本内容 100% 防注入；
3. **敏感凭证防泄露**：子进程与服务启动自动过滤环境变量敏感密钥；
4. **符号链接穿透清理防护**：构建与清理脚本引入 `safeRemove` 判定，安全防穿透。
